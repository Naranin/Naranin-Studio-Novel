# 🍓 Naranin Novel Studio — เว็บไซต์นิยายส่วนตัวสไตล์น่ารักสดใส

เว็บไซต์สำหรับอ่านและลงนิยายส่วนตัว รองรับการเปิดออนไลน์ผ่าน **GitHub Pages** ได้ทันทีโดยไม่ต้องติดตั้งหรือรันคำสั่งใดๆ 100%

---

## ✨ ฟีเจอร์เด่น
1. **ดีไซน์น่ารักสดใส ไม่จืด:** โทนสีชมพูพาสเทล ลูกกวาด และครีมอบอุ่น ใช้ฟอนต์ 'Mali' และ 'Prompt' สไตล์เกาหลี/ญี่ปุ่น
2. **ระบบอ่านนิยาย (Reader View):**
   - ปรับขนาดตัวอักษรได้ (A- / A+)
   - ปรับธีมสีพื้นหลังได้ 4 แบบ: ครีมอบอุ่น, พาสเทลชมพู, ขาวสบายตา, กลางคืนนุ่มนวล
   - ปุ่มเปลี่ยนตอนก่อนหน้า/ถัดไป
3. **ระบบติดเหรียญรายตอน (Coin Lock):**
   - ตั้งค่าตอนฟรี หรือตอนติดเหรียญได้ใน `novels.js`
   - ระบบเบลอตัวอย่างเนื้อหา และปุ่มกดปลดล็อกตอน
   - จดจำประวัติการปลดล็อกไว้ในเครื่องอัตโนมัติ (LocalStorage)
4. **ระบบเติมเงิน (Coin Top-up):**
   - แสดงแพ็กเกจเติมเหรียญพร้อมโบนัส
   - แสดง QR Code พร้อมเพย์ของนักเขียนโดยตรง
   - มีปุ่มจำลองการยืนยันรับเหรียญทันที
5. **ระบบโดเนตนักเขียน (Donation & Stickers):**
   - ส่งสติกเกอร์ของขวัญน่ารักๆ (🍓 สตรอว์เบอร์รี, 🧋 ชานมไข่มุก, 🍰 เค้ก, 👑 มงกุฎ)
   - แนบข้อความให้กำลังใจ แสดงผลบนกระดานผู้สนับสนุน (Donation Board) แบบ Real-time

## 🚀 วิธีนำขึ้น GitHub เพื่อให้ออนไลน์ทันที (ใน 2 นาที)

1. เข้าเว็บไซต์ [GitHub.com](https://github.com) แล้วล็อกอิน
2. กดปุ่ม **New** (สีเขียว) เพื่อสร้าง Repository ใหม่:
   - ตั้งชื่อ เช่น `my-novels` หรือ `naranin-studio`
   - เลือกเป็น **Public**
   - ติ๊กถูกที่ `Add a README file` หรือปล่อยว่างไว้ก็ได้ แล้วกด **Create repository**
3. กดปุ่ม **Add file** -> **Upload files**
4. ลากไฟล์ `index.html` และ `novels.js` มาวาง แล้วกดปุ่มเขียว **Commit changes**
5. เปิดหน้าเว็บให้ออนไลน์:
   - ไปที่แท็บ **Settings** ของ Repository นั้น
   - ที่เมนูด้านซ้าย เลือก **Pages**
   - ตรงหัวข้อ **Branch** ให้เลือกเป็น `main` (หรือ `master`) แล้วโฟลเดอร์เลือก `/ (root)` แล้วกด **Save**
6. รอประมาณ 30-60 วินาที จะได้ลิงก์เว็บไซต์ของคุณทันที เช่น:
   `https://your-username.github.io/my-novels/`

## 📝 วิธีแก้ไขและเพิ่มนิยายของตัวเอง
เปิดไฟล์ `novels.js` ด้วยโปรแกรมแก้ไขข้อความ (เช่น Notepad หรือ VS Code):
- **เปลี่ยนข้อมูลส่วนตัว:** เปลี่ยนชื่อนักเขียน, ข้อความแนะนำตัว, ลิงก์รูปภาพ, และเบอร์พร้อมเพย์ที่ `SITE_CONFIG`
- **เพิ่ม/ลด ตอนนิยาย:** แก้ไขในตัวแปร `NOVELS`
  - หากต้องการให้อ่านฟรี: กำหนด `isLocked: false, coinPrice: 0`
  - หากต้องการติดเหรียญ: กำหนด `isLocked: true, coinPrice: 3` (หรือตามจำนวนเหรียญที่ต้องการ)
