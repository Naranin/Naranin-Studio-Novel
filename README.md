# 🍀 Naranin Novel & Webtoon Studio — เว็บไซต์นิยายและนิยายภาพการ์ตูน (Pastel Green)

เว็บไซต์สำหรับอ่านและลงผลงานส่วนตัว รองรับทั้ง **นิยายบรรยาย (Text Novel)** และ **นิยายภาพ / การ์ตูนเว็บตูน (Comic & Webtoon)** ในที่เดียว พร้อมดีไซน์น่ารักสดใสโทนเขียวพาสเทล (มงคลคนเกิดวันพุธ) อัปโหลดขึ้น **GitHub Pages** แล้วออนไลน์ได้ทันที 100%

---

## ✨ ฟีเจอร์ที่พัฒนาครบถ้วนตามความต้องการ

1. **รองรับ 2 รูปแบบผลงาน (นิยายบรรยาย & นิยายภาพการ์ตูน):**
   - **นิยายบรรยาย:** หน้าอ่านปรับขนาดตัวอักษรและสีพื้นหลังได้ 4 ธีม
   - **นิยายภาพ & การ์ตูนเว็บตูน:** หน้าอ่านแบบ Webtoon Viewer แสดงภาพต่อเนื่องแนวตั้งคมชัด พร้อมกล่องคำบรรยายหรือบทสนทนา
   - มีแท็บกรองบนหน้าแรก: ทั้งหมด / นิยายบรรยาย / นิยายภาพ & การ์ตูน
2. **ห้องนักเขียน (Writer Studio) จัดการทุกอย่างบนหน้าเว็บ:**
   - กดปุ่ม **"✍️ ห้องนักเขียน"** บนแถบเมนู (รหัส PIN เริ่มต้น: `1234`)
   - **เพิ่ม/แก้ไขผลงาน:** เลือกว่าเป็น "นิยายบรรยาย" หรือ "นิยายภาพ/การ์ตูน"
   - **เขียนตอนใหม่:** สามารถอัปโหลดรูปภาพการ์ตูนจากเครื่องได้ทีละหลายๆ รูปพร้อมกัน พร้อมพรีวิวตัวอย่าง
   - **ระบบติดเหรียญ:** เลือกสลับ "อ่านฟรี" หรือ "🔒 ติดเหรียญ" พร้อมระบุราคาเหรียญ (เช่น 3, 4, 5 เหรียญ)
3. **อัปโหลดรูปโปรไฟล์และรูปปกนิยายจากเครื่องได้เอง:**
   - มีปุ่มเลือกรูปภาพจากมือถือหรือคอมพิวเตอร์ได้โดยตรง
   - มีระบบบีบอัดและปรับขนาดภาพอัตโนมัติเพื่อให้เว็บโหลดเร็ว ไม่หนักเครื่อง
4. **คุ้มครองลิขสิทธิ์ตาม พ.ร.บ. ลิขสิทธิ์ พ.ศ. 2537 (และที่แก้ไขเพิ่มเติม):**
   - มีแถบประกาศคุ้มครองทรัพย์สินทางปัญญาทั้งในส่วนท้ายของเว็บไซต์ (Footer) และในหน้าอ่าน
5. **ระบบเหรียญและโดเนต (Top-up & Donation):**
   - หน้าต่างเติมเงินแสดง QR Code พร้อมเพย์ของนักเขียนโดยตรง
   - ระบบของขวัญสติกเกอร์ (🍀 ใบโคลเวอร์, 🍵 ชาเขียวมัทฉะ, 🍈 เมลอน, 💐 ช่อดอกไม้, 👑 มงกุฎ) พร้อมกระดานผู้สนับสนุนใจดี

## 🚀 วิธีนำขึ้น GitHub เพื่อให้ออนไลน์ทันที

1. ล็อกอินเข้า [GitHub.com](https://github.com)
2. กดปุ่ม **New** สร้าง Repository ใหม่ (เช่น `naranin-studio` หรือ `my-novels`) ตั้งค่าเป็น **Public**
3. กด **Add file** > **Upload files** ลากทั้ง 3 ไฟล์ (`index.html`, `novels.js`, `README.md`) วางลงไปแล้วกด **Commit changes**
4. ไปที่แท็บ **Settings** > **Pages** > เลือก Branch: `main` โฟลเดอร์: `/ (root)` แล้วกด **Save**
5. รอประมาณ 30-60 วินาที จะได้รับลิงก์เว็บไซต์ของคุณพร้อมใช้งานทันทีค่ะ
