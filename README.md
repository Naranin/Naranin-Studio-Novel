# 🌸 Naranin Studio — คลังนิยายรัก & การ์ตูนสดใส พาสเทลสามสี (ชมพู-เขียว-ฟ้า)

เว็บไซต์อ่านและลงผลงานส่วนตัวสำหรับ **นักเขียน** รองรับทั้งนิยายบรรยายและการ์ตูนภาพ AI ดีไซน์น่ารักสดใสด้วยโทนสี **ชมพูพาสเทล - เขียวพาสเทล - ฟ้าพาสเทล** นำขึ้น **GitHub Pages** แล้วออนไลน์ได้ทันทีโดยไม่ต้องเขียนโค้ด

---

## ✨ สรุปฟีเจอร์สำคัญตามที่คุณกำหนด

1. **รหัสเข้าห้องนักเขียน (PIN):**
   - รหัสเริ่มต้นคือ `785` (ในหน้าต่างกรอกรหัสจะไม่มีข้อความบอกใบ้รหัส เพื่อความปลอดภัย)
   - สามารถเปลี่ยนรหัส PIN เองได้ตลอดเวลาในหน้าตั้งค่าของห้องนักเขียน
2. **ระบบการเงินธนาคารกรุงเทพ & สแกน QR Code:**
   - ใช้บัญชี **ธนาคารกรุงเทพ (Bangkok Bank)**
   - มีช่องระบุเลขที่บัญชีและชื่อบัญชี พร้อมปุ่มคัดลอกเลขบัญชี
   - สามารถอัปโหลดรูปภาพ **สแกนโค้ด (QR Code)** ของคุณจากเครื่องขึ้นหน้าเว็บได้โดยตรง เพื่อให้นักอ่านสแกนจ่ายเงินได้ทันที
3. **จำกัดความยาวตอนนิยายสูงสุด 1,200 คำ:**
   - ในกล่องพิมพ์เนื้อหามีระบบนับคำแบบ Real-time: `X / 1,200 คำ`
   - หากเนื้อหาเกิน 1,200 คำ ระบบจะแจ้งเตือนสีแดงและล็อกปุ่มบันทึกไว้จนกว่าจะตัดทอนลงมาไม่เกินกำหนด
4. **ธีมพาสเทล 3 สี (ชมพู - เขียว - ฟ้า):**
   - โทนสีหวานละมุน สดใส ไม่จืดชืด ออกแบบให้สบายตาและน่าอ่านทั้งบนมือถือและคอมพิวเตอร์
5. **ระบบคอมเมนต์ & กดหัวใจใต้ตอน:**
   - ใต้ทุกตอนมีปุ่ม **"❤️ กดใจให้ตอนนี้"**
   - มีช่องให้ผู้อ่านพิมพ์ชื่อและข้อความ **คอมเมนต์พูดคุยกับนักเขียน** พร้อมแสดงรายการคอมเมนต์แบบแยกรายตอน
6. **ระบบยอดวิวจริง & ปุ่มเพิ่มวิวเฉพาะนักเขียน:**
   - เมื่อมีผู้อ่านเปิดอ่านเรื่อง ยอดวิวจะเพิ่มขึ้นตามจริงอัตโนมัติ
   - ภายในห้องนักเขียน จะมีปุ่มสำหรับนักเขียนคนเดียวในการกดเพิ่มยอดวิว (`+100`, `+500`, หรือพิมพ์ระบุยอดวิวเอง)
7. **ปุ่มกดจบเรื่อง:**
   - ในห้องนักเขียนมีปุ่ม **"🏁 กดจบเรื่องนี้"** สำหรับกดเปลี่ยนสถานะเรื่องเป็น "จบแล้ว" ได้ในคลิกเดียว
8. **ใช้คำว่า "นักเขียน" ทั้งหมด:**
   - ทุกส่วนของเว็บไซต์ใช้คำว่า "นักเขียน" ทั้งสำหรับนิยายและการ์ตูนภาพ AI
9. **คุ้มครองลิขสิทธิ์:**
   - ระบุข้อความคุ้มครองสิทธิ์ตาม **พระราชบัญญัติลิขสิทธิ์ พ.ศ. 2537 (และที่แก้ไขเพิ่มเติม)** อย่างถูกต้อง

## 🚀 วิธีนำขึ้น GitHub เพื่อให้ออนไลน์ทันที

1. ล็อกอินเข้า [GitHub.com](https://github.com)
2. สร้าง Repository ใหม่ ตั้งชื่อเช่น `naranin-studio` (เลือกสถานะเป็น **Public**)
3. กด **Add file** > **Upload files** ลากไฟล์ `index.html`, `novels.js`, `README.md` ไปวาง แล้วกด **Commit changes**
4. ไปที่ **Settings** > **Pages** > เลือก Branch: `main` โฟลเดอร์: `/ (root)` แล้วกด **Save**
5. รอ 1 นาที จะได้รับลิงก์เว็บไซต์พร้อมใช้งานทันทีค่ะ
