# 🍀 Naranin Studio — คลังนิยาย & การ์ตูนสดใส โทนเขียวพาสเทล (พร้อมระบบ E-book PDF/ePub)

เว็บไซต์อ่านและลงผลงานส่วนตัวสำหรับ **นักเขียน** รองรับทั้งนิยายบรรยาย การ์ตูนภาพ AI และฉบับ E-book (PDF + ePub) ดีไซน์น่ารักสดใสด้วยโทนสี **เขียวพาสเทล (Pastel Green)** นำขึ้น **GitHub Pages** แล้วออนไลน์ได้ทันทีโดยไม่ต้องเขียนโค้ด

---

## ✨ สรุปฟีเจอร์สำคัญทั้งหมด

1. **ระบบกดใจ (1 ไอดีกดได้ 1 ครั้ง):**
   * นักอ่านแต่ละคนสามารถกดหัวใจให้เรื่องได้ 1 ครั้ง และในแต่ละตอนได้เพียง 1 ครั้งเท่านั้น (กดซ้ำจะเป็นการยกเลิก/สลับออก ไม่สามารถปั๊มหัวใจซ้ำได้)
2. **ระบบเก็บเข้าชั้นหนังสือ (Bookshelf):**
   * มีปุ่ม **"🔖 เพิ่มเข้าชั้น"** ที่การ์ดเรื่อง หน้ารายละเอียด และหน้าอ่าน
   * มีปุ่มเมนู **"📚 ชั้นหนังสือ"** ด้านบนเพื่อเปิดดูรายชื่อเรื่องที่บันทึกไว้ และกดอ่านต่อได้ทันที
3. **ระบบร้านค้า E-book (รองรับทั้งไฟล์ PDF และ ePub):**
   * สามารถเปิดขาย E-book รวมเล่มจบสมบูรณ์สำหรับแต่ละเรื่องได้
   * นักอ่านสามารถเลือกชำระด้วยเหรียญ หรือสแกนชำระผ่านธนาคารกรุงเทพ
   * เมื่อปลดล็อก/ชำระเงินแล้ว ระบบจะแสดงปุ่ม **"📥 ดาวน์โหลด PDF"** และ **"📥 ดาวน์โหลด ePub"** ให้นักอ่านกดดาวน์โหลดไฟล์ได้ตลอดเวลา
   * ภายในห้องนักเขียน สามารถเปิด/ปิด E-book ตั้งราคา และใส่ลิงก์ดาวน์โหลดไฟล์ PDF และ ePub ได้โดยตรง
4. **โหมดสีพื้นหลังขณะอ่าน (Reader Modes):**
   * ☀️ **กลางวัน:** พื้นหลังสีขาวสะอาด คมชัด สว่างสบายตา
   * 🍃 **สบายตา:** พื้นหลังสีครีมมินต์นวลตา ถนอมสายตา ลดแสงสะท้อน
   * 🌙 **กลางคืน:** พื้นหลังดาร์กโหมดโทนป่าเข้มลึก สบายตา ไม่อ่อนล้าสายตาในที่มืด
5. **รหัสเข้าห้องนักเขียน (PIN):**
   * รหัสเริ่มต้นคือ `785` (ในหน้าต่างกรอกรหัส **ไม่มีข้อความบอกใบ้รหัส** เพื่อความปลอดภัย)
   * สามารถเปลี่ยนรหัส PIN เองได้ตลอดเวลาในหน้าตั้งค่าของห้องนักเขียน
6. **ระบบการเงินธนาคารกรุงเทพ & สแกนโค้ด (QR Code):**
   * ใช้บัญชี **ธนาคารกรุงเทพ (Bangkok Bank)**
   * มีช่องระบุเลขที่บัญชีและชื่อบัญชี พร้อมปุ่มคัดลอกเลขบัญชี
   * สามารถอัปโหลดรูปภาพ **สแกนโค้ด (QR Code)** จากเครื่องของคุณ เพื่อให้นักอ่านสแกนจ่ายเงินได้ทันที
7. **จำกัดความยาวตอนนิยายสูงสุด 1,200 คำ:**
   * ในกล่องพิมพ์เนื้อหามีระบบนับคำแบบ Real-time: `X / 1,200 คำ`
   * หากเนื้อหาเกิน 1,200 คำ ระบบจะแสดงแถบเตือนสีแดงและล็อกปุ่มบันทึกไว้จนกว่าจะตัดทอนลงมาไม่เกินกำหนด
8. **ระบบคอมเมนต์ใต้ตอน:**
   * มีช่องพิมพ์ชื่อและข้อความ **คอมเมนต์พูดคุยกับนักเขียน** พร้อมแสดงรายการคอมเมนต์ใต้ตอนนั้นๆ
9. **ระบบยอดวิวจริง & ปุ่มเพิ่มวิวเฉพาะนักเขียน:**
   * ยอดวิวจะนับเพิ่มขึ้นตามจริงอัตโนมัติเมื่อมีผู้อ่านเปิดเข้าชมเรื่อง
   * ภายในห้องนักเขียน จะมีปุ่มสำหรับนักเขียนคนเดียวในการกดเพิ่มยอดวิว (`+100`, `+500`, หรือกำหนดเอง)
10. **ปุ่มกดจบเรื่อง:**
    * ในห้องนักเขียนมีปุ่ม **"🏁 กดจบเรื่องนี้"** สำหรับเปลี่ยนสถานะเรื่องเป็น "จบแล้ว" ได้ในคลิกเดียว
11. **ใช้คำว่า "นักเขียน" ทั้งหมด:**
    * ทุกส่วนของเว็บไซต์ใช้คำว่า "นักเขียน" ทั้งสำหรับนิยายและการ์ตูนภาพ AI
12. **คุ้มครองลิขสิทธิ์:**
    * ระบุข้อความคุ้มครองสิทธิ์ตาม **พระราชบัญญัติลิขสิทธิ์ พ.ศ. 2537 (และที่แก้ไขเพิ่มเติม)** อย่างถูกต้อง

## 🚀 วิธีนำขึ้น GitHub เพื่อให้ออนไลน์ทันที

1. ล็อกอินเข้า [GitHub.com](https://github.com)
2. สร้าง Repository ใหม่ ตั้งชื่อเช่น `naranin-studio` (เลือกสถานะเป็น **Public**)
3. กด **Add file** > **Upload files** ลากไฟล์ `index.html`, `novels.js`, `README.md` ไปวาง แล้วกด **Commit changes**
4. ไปที่ **Settings** > **Pages** > เลือก Branch: `main` โฟลเดอร์: `/ (root)` แล้วกด **Save**
5. รอ 1 นาที จะได้รับลิงก์เว็บไซต์พร้อมใช้งานทันทีค่ะ
